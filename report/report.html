7 · Multiplayer & Hosting

  • Host-authoritative room with 5-char share codes; join by code; live round sync, picks, reveals, scores — verified end-to-end with two concurrent browser tabs.
  • Triple transport: PeerJS WebRTC (cross-device, no server), BroadcastChannel, and a storage-event + polling bus (same-browser, bulletproof). Host keeps the room alive even when the free broker throttles.
  • GitHub Pages ready: static files, .nojekyll included, README with 3-step deploy. Cross-device play uses the free PeerJS cloud (no keys); same-browser play never needs it.
